## 📌 프로젝트 소개

**수학 실험실(MathLab)**은 추상적인 수학 개념을 학생들이 눈으로 직접 보고, 마우스와 터치로 조작하며 직관적으로 이해할 수 있도록 설계된 웹 기반 수학교육 플랫폼입니다.

복잡한 수식 암기 위주의 학습에서 벗어나, 동적 그래프·도형 시뮬레이션·수학적 게임·실생활 모델링을 통해 **체험형 수학 탐구(Hands-on Math Discovery)**를 실현합니다.

---

## 🌟 핵심 특징

- 🚀 **무설치 단일 파일 실행**: 별도의 프로그램 설치나 복잡한 서버 구성 없이, 웹 브라우저만 있으면 `index.html` 단 하나로 어디서나 1초 만에 실행됩니다.
- 📱 **모바일 & 전자칠판 최적화**: 교실 프로젝터, 스마트 전자칠판, 태블릿, 학생 개인 스마트폰 등 모든 기기 화면에 맞춤형 반응형 UI를 제공합니다.
- 🎮 **게이미피케이션 & 실시간 랭킹**: 흥미진진한 도전 과제와 실시간 명예의 전당(리더보드)을 통해 학생들의 자발적 탐구 몰입을 유도합니다.
- 🏫 **2022 개정 교육과정 연계**: 초·중·고등학교 정규 수학 교과 단원 및 성취기준에 맞춘 체계적인 카테고리 분류 및 키워드 검색을 지원합니다.

## 📂 카테고리 구성 (총 160여 개 앱)

수학 실험실은 목적과 학습 단계에 따라 크게 3개 섹션으로 구성되어 있습니다.

### 1. 📊 교과 수학 개념 탐구 (Concepts)
정규 교육과정의 핵심 수학 원리를 시각화하고 동적으로 조작해보는 탐구 도구입니다.
- **삼각함수 DJ**: 파동의 진폭과 주기를 실시간으로 조율하며 삼각함수 그래프의 변화 관찰
- **다항함수 해부학**: 삼차·사차함수의 도함수, 접선의 방정식, 극대·극소 및 비율관계 동적 실험
- **3D 도형 공작소**: 정다면체와 회전체의 전개도 3차원 애니메이션
- **유리·무리함수 공작소**: 점근선과 곡선의 이동을 슬라이더로 조작하며 그래프 대칭성 탐구
- **경사하강법 & 뉴턴-랩슨 탐구**: 인공지능과 수치해석의 기초가 되는 최적화 알고리즘 시각화

### 2. 🎮 수학 게임 & 퍼즐 (Games)
수학적 논리력, 공간지각력, 전략적 사고를 기를 수 있는 두뇌 게임 모음입니다.
- **1024 마스터 / 2048 과일 드롭**: 거듭제곱과 기하급수적 성장을 체득하는 블록 병합 게임
- **소수 헌터**: 빠르게 떨어지는 숫자 중 소수를 순발력 있게 판별하는 서바이벌 게임
- **Make 24 / 주산 마스터**: 사칙연산과 수 감각을 연마하는 연산 퍼즐
- **정다면체 미로 / 위상 링 풀기**: 오일러 지표와 위상수학적 연결성을 활용한 공간 탈출
- **비둘기집 원리 & 죄수의 딜레마**: 이산수학과 게임이론의 유명한 딜레마 시뮬레이션

### 3. 💰 실생활 수학 응용 (Applications)
일상생활 속 금융, 경제, 확률, 통계 모델링을 직접 체험하는 시뮬레이터입니다.
- **경제수학 생애 주기 시뮬레이터**: 소득, 소비, 저축 곡선을 모델링하여 생애 자산 흐름 예측
- **금융 수학 타임머신 & 대출 상환기**: 단리와 복리, 원리금균등상환의 차이를 한눈에 비교
- **로또 시뮬레이터 & 네트워크**: 대수의 법칙과 극악의 당첨 확률을 대량 시뮬레이션으로 체감
- **몬티홀 딜레마 쇼**: 조건부 확률의 역설을 반복 표본 실험으로 증명

## 🛠️ 기술 스택

- **Frontend**: Pure HTML5, Modern CSS3, Vanilla JavaScript (ES6+)
- **Math Rendering**: [KaTeX](https://katex.org/) (LaTeX 고속 수식 렌더링)
- **Graphics & Animation**: HTML5 2D Canvas, WebGL, SVG
- **Database & Ranking**: Firebase Realtime Database
- **Architecture**: Self-contained Single-page Bundle (단일 파일 독립 번들)

## 🚀 실행 및 배포 방법

### 1. 로컬에서 실행하기
1. 이 저장소의 `index.html` 파일을 다운로드합니다.
2. 다운로드한 `index.html` 파일을 더블클릭하면 모든 브라우저(Chrome, Edge, Safari 등)에서 즉시 실행됩니다.

### 2. GitHub Pages 무료 배포하기
1. GitHub 저장소의 `Settings` → `Pages`로 이동합니다.
2. **Branch**를 `main` (또는 `master`), 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
3. 1~2분 후 발급되는 `https://<사용자아이디>.github.io/<저장소이름>/` 주소로 전 세계 어디서든 접속할 수 있습니다.

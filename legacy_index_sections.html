📱 모바일 설정 초기화 0%! 「개인판」 3단계 가이드

모바일 브라우저(아이폰 Safari, 안드로이드 Chrome, 카카오톡 인앱 브라우저 등)의 강화된 개인정보 보호 정책(ITP)으로 인해, 웹앱 종료 시 입력했던 API 키와 시트 ID가 사라지는 현상이 발생할 수 있습니다.

💡 이를 근본적으로 해결하기 위해 구글 서버 측에 API 키를 영구 저장하는 [개인 배포판]을 제공합니다! 딱 3단계만 따라하시면 평생 초기화 없는 나만의 AI 과외 선생님이 생깁니다.

1️⃣ 1단계 : 템플릿 시트 사본 만들기

  1. 안내 배너의 [👉 모바일 전용 개인판 앱 복제하기] 버튼을 클릭합니다.
  2. 화면에 나타나는 [사본 만들기] 파란색 버튼을 눌러 내 구글 드라이브로 가져옵니다.

2️⃣ 2단계 : 나만의 단독 웹앱으로 배포하기

  1. 복사된 시트 상단 메뉴에서 [확장 프로그램] ➔ [Apps Script]를 클릭하여 코드 편집기를 엽니다.
  2. 우측 상단의 파란색 [배포(Deploy)] ➔ [새 배포(New deployment)]를 클릭합니다.
  3. 좌측 톱니바퀴 아이콘(⚙️)을 눌러 [웹 앱(Web app)]을 선택합니다.
  4. 설정 항목을 아래와 같이 정확히 맞춰주세요:
    • 설명: 제미나이 수학과외 개인판
    • 다음 계정으로 실행(Execute as): 나(Me - 본인 이메일) ⚠️ (가장 중요!)
    • 액세스 권한(Who has access): 나(Only myself) 또는 모든 사용자(Anyone)
  5. [배포] 버튼을 누르고, 권한 승인 창이 뜨면 [고급] ➔ [~로 이동(안전하지 않음)] ➔ [허용]을 눌러줍니다.
  6. 완료 후 화면에 나타나는 [웹 앱 URL (https://script.google.com/macros/s/.../exec)]을 복사하여 스마트폰 홈 화면에 추가하거나 즐겨찾기합니다!

3️⃣ 3단계 : API 키 최초 1회 등록하기

  1. 스마트폰이나 PC에서 복사한 웹 앱 URL로 접속합니다.
  2. 화면 중앙의 [🔑 API 키 영구 등록] 창에 본인의 Gemini API 키를 입력하고 저장합니다.
  3. ✨ 완료! 이제 브라우저를 닫거나 스마트폰을 재부팅해도 API 키가 절대 초기화되지 않으며, 모든 질문 기록이 내 시트의 [질문기록] 탭에 차곡차곡 자동 저장됩니다!
